# TurtleBot3 Supervisory Control using FlexBE and Reinforcement Learning

## Goal
Develop a supervisory control framework for a TurtleBot3 robot using:

- ROS2 Humble
- Gazebo
- FlexBE
- Hierarchical Finite State Machines (HFSM)
- Reinforcement Learning
- Process Mining
- Linear Temporal Logic (LTL)

## Project Phases

1. Infrastructure Setup
2. Custom FlexBE States
3. Autonomous Robot Behaviors
4. HFSM Development
5. Supervisory Controller
6. Reinforcement Learning
7. Process Mining
8. LTL Verification
